# Security policy

Do not include credentials, customer data, or exploit details in public issues. A private reporting contact must be configured before a public release; none exists yet.

This repository is pre-product and not approved for live restaurant use. Required controls and open threats are documented in docs/security/THREAT_MODEL.md. No security certification is claimed. Authentication, tenant isolation, scans, SBOM, backup recovery, and external human review remain release gates.
