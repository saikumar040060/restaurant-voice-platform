# Incident response skeleton

Before pilot: assign incident owner and escalation contacts. Detect via error, uncertain-order, access-denial, and provider-health alerts. Disable affected automated actions with the kill switch; route calls to staff if safe. Do not retry uncertain orders. Preserve redacted audit evidence, revoke compromised access, assess affected tenants, reconcile provider outcomes, then validate recovery. Record timeline, customer impact, notification decisions, and corrective tests. Incident tooling is not implemented yet.
